# Informe del proyecto - Recetario

## 1. Tema elegido

Elegimos desarrollar un recetario de cocina porque nos permite trabajar con recetas, ingredientes y relaciones entre recetas y subrecetas.

El proyecto permitirá organizar un catálogo de recetas y, en futuras entregas, incorporar funcionalidades relacionadas con la planificación de comidas y la preparación de recetas.

## 2. Objetos mutables e inmutables

En el proyecto se trabajará principalmente con estructuras mutables para almacenar y modificar los datos de las recetas.

Las listas de Python son mutables, por lo que pueden modificarse durante la ejecución del programa.

Los diccionarios utilizados para representar los registros leídos desde los archivos CSV también son mutables.

Los valores de texto, como los nombres de las recetas, son cadenas (`str`) y son inmutables.

## 3. Fuente de datos

Los datos utilizados por el proyecto provienen de los archivos CSV proporcionados por la materia:

- `recetas.csv`
- `ingredientes.csv`
- `subrecetas.csv`
